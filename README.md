# «5 букв»

Консольная игра на Java: нужно угадать русское слово из пяти букв за шесть попыток.

## Текущее состояние: MR2

Реализованы:

- загрузка и проверка словаря;
- воспроизводимый выбор ответа по seed;
- игровая сессия с историей и ограничением попыток;
- проверка пользовательского ввода;
- подсказки по буквам с корректным учётом повторов;
- победа, поражение и запрет ходов после завершения;
- одна полноценная партия через консоль;
- replay партии по seed и списку входных строк;
- обязательные тесты MR1 и MR2 и дополнительные проверки.

Меню и несколько партий без перезапуска будут добавлены в MR3.

## Требования

- JDK 25 или новее.
- Gradle отдельно устанавливать не нужно: используется Gradle Wrapper.

В IntelliJ IDEA нужно выбрать JDK 25+ для Gradle JVM и запуск тестов через Gradle.

## Запуск

### Windows PowerShell

Перед интерактивным запуском настройте UTF-8 в текущем окне PowerShell:

```powershell
[Console]::InputEncoding = [System.Text.UTF8Encoding]::new($false)
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
```

Запуск игры:

```powershell
.\gradlew.bat --console=plain run
.\gradlew.bat --console=plain run --args="--seed 42"
.\gradlew.bat --console=plain run --args="--help"
```

Параметр --console=plain отключает обновляемый индикатор Gradle,
который может мешать интерактивному вводу.

Если после изменения кодировки пятибуквенные слова всё ещё отклоняются по длине, повторите запуск без использования ранее запущенного Gradle daemon:

```powershell
.\gradlew.bat --no-daemon --console=plain run --args="--seed 42"
```


### Linux и macOS

Используйте терминал с кодировкой UTF-8:

## Правила игры

Программа загадывает слово из пяти букв. На угадывание даётся
шесть допустимых попыток.

Ввод:

- регистр не учитывается;
- внешние пробелы удаляются;
- принимаются пять русских букв без ё;
- слово должно присутствовать в словаре;
- пробелы внутри слова, цифры и знаки отклоняются.

Некорректный ввод не изменяет историю, счётчик попыток и статус партии.
Повторное допустимое слово расходует попытку.

После принятого слова выводятся подсказки:

- ✅ - буква совпала на той же позиции;
- 🟡 - буква совпала с ещё не использованной буквой на другой позиции;
- ❌ - для буквы не осталось совпадений.

Например, для ответа «озеро» и попытки «арбуз»:

```text
❌🟡❌❌🟡 арбуз
Осталось попыток: 5
```

### Повторяющиеся буквы

Сначала учитываются все точные совпадения, затем распределяются
оставшиеся буквы ответа.

Для ответа «сорок» и строки «оооом» результат сравнения:

```text
❌✅❌✅❌
```

Обе буквы «о» расходуются на точные совпадения на второй
и четвёртой позициях.

Это искусственный пример проверки алгоритма: обычная игра дополнительно требует наличия введённого слова в словаре.


### Завершение партии

- Угадывание, в том числе на шестой попытке, означает победу.
- Шесть допустимых неверных попыток означают поражение.
- При поражении показывается загаданное слово.
- После завершения партия больше не принимает попытки.
- Конец входного потока прерывает незавершённую партию без поражения.
- Для новой партии сейчас нужно повторно запустить программу.


## Seed и воспроизводимость

Без --seed начальное значение выбирается автоматически
и печатается в консоли. Его можно передать при следующем запуске.

Seed может быть любым целым числом в диапазоне Java long:
от -9223372036854775808 до 9223372036854775807.

Одинаковый набор слов и одинаковый seed дают одинаковый ответ.
Изменение состава словаря может изменить ответ при том же seed.

## Replay - воспроизведение партии

Windows:

```powershell
.\gradlew.bat --console=plain run --args="replay --seed 42 --guesses арбуз сорок озеро"
```

Linux и macOS:

```bash
./gradlew --console=plain run --args="replay --seed 42 --guesses арбуз сорок озеро"
```

Replay создаёт новую партию и последовательно обрабатывает переданные строки без чтения с клавиатуры.

Формат команды:

```text
replay --seed <целое число> --guesses [строки...]
```

- Seed обязателен.
- Порядок параметров фиксирован.
- После --guesses каждый аргумент считается строкой сценария.
- Каждый шаг сохраняет исходную строку и результат обработки.
- Некорректные слова отображаются как отклонённые и не расходуют попытки.
- Строки после победы или поражения отклоняются с причиной "Партия уже завершена".
- Пустой список разрешён.
- Если партия не завершена, выводится "Партия не завершена", ответ при этом не раскрывается.

Пример пустого сценария:

```powershell
.\gradlew.bat --console=plain run --args="replay --seed 42 --guesses"
```

Воспроизводимость требует одинаковых seed, словаря, лимита попыток и правил игры. Сейчас CLI использует основной словарь и лимит 6 попыток.

## Коды завершения

- 0 - нормальное завершение, включая победу, поражение, конец ввода, воспроизведение незавершённого сценария и вывод справки;
- 1 - ошибка выполнения приложения, например чтения ресурса или ввода;
- 2 - некорректные аргументы командной строки.

Отклонённое игровое слово не является ошибкой запуска.

При ненулевом коде приложения задача Gradle run тоже завершается ошибкой.

## Словарь

Основной ресурс: src/main/resources/dictionary.txt.

Формат: одно слово в строке, пять русских букв в нижнем регистре, без ё.

При загрузке удаляются внешние пробелы; пустые строки и комментарии,
начинающиеся с #, пропускаются. Некорректные слова вызывают ошибку.

WordDictionary допускает любой непустой набор корректных слов.
При создании игровой партии GameService требует минимум 50 уникальных слов.

## Устройство

- word/WordRules — общие правила формата и нормализация ввода.
- dictionary/WordDictionary — неизменяемый словарь.
- dictionary/DictionaryLoader — загрузка ресурсов в UTF-8.
- game/GameSession — состояние партии и история принятых слов.
- game/GameService — создание игры и обработка попыток.
- game/LetterMatcher — сравнение букв в два прохода.
- game/LetterStatus — статусы совпадения букв.
- game/GuessResult — принятый или отклонённый ход.
- game/GuessRejectionReason — причины отклонения.
- game/GameStatus — состояния IN_PROGRESS, WIN и LOSE.
- replay/ReplayService — воспроизведение через обычный applyGuess.
- replay/ReplayStep — исходная строка и результат её обработки.
- replay/ReplayResult — неизменяемый итог воспроизведения.
- cli/CommandLineParser и LaunchOptions — разбор режима запуска.
- cli/ConsoleGame — цикл одной консольной партии.
- cli/ConsoleReplay — вывод шагов воспроизведения.
- cli/ConsoleFormatter — текстовое представление результатов.
- Main — создание компонентов и запуск выбранного режима.

Игровая логика отделена от консольного ввода-вывода.

Порядок слов стабилен благодаря сортировке.
Счётчик попыток и статус сессии вычисляются по истории.
История доступна как неизменяемый снимок.
Результаты ходов и replay защищены от внешнего изменения.

Алгоритм сравнения букв проверяет формат, но не принадлежность словарю.
Допустимость слова для конкретной партии проверяет игровой сервис.


## Проверки

Windows:

```powershell
.\gradlew.bat test
.\gradlew.bat spotlessApply check
```

Linux и macOS:

```bash
./gradlew test
./gradlew spotlessApply check
```

Все обязательные тесты MR1 и MR2 включены.
Отключены только три заготовки MR3.

Проверяются:

- словарь, его загрузка и границы допустимого размера;
- seed и независимость партий;
- нормализация и отклонение неверного ввода;
- совпадения букв, повторы и приоритет точных совпадений;
- победа на последней попытке и поражение;
- неизменность состояния после отклонённого хода;
- запрет ходов после завершения;
- консольный вывод и аргументы запуска;
- replay, включая ошибочные строки и ввод после завершения.

Тесты CLI запускают приложение отдельным процессом через CliRunner.
Они передают ввод в UTF-8 и не проверяют настройки интерактивного терминала Windows.
