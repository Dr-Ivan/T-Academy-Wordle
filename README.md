# «5 букв»

Консольная игра на Java: нужно угадать русское слово из пяти букв за шесть попыток.

## Текущее состояние: MR1

Реализовано:

- загрузка словаря из ресурсов в UTF-8;
- проверка слов, удаление повторов и стабильная сортировка;
- выбор ответа с воспроизводимостью по seed;
- модель сессии с историей, лимитом попыток и статусами IN_PROGRESS, WIN, LOSE;
- защита завершённой сессии от новых попыток;
- демонстрационный запуск с параметром --seed;
- обязательные тесты MR1 и дополнительные проверки.

Сейчас программа создаёт сессию, выводит её параметры, включая ответ,
и завершается. Ввод попыток и подсказки появятся в MR2, меню будет реализовано в MR3.

## Требования

- JDK 25 или новее.
- Gradle отдельно устанавливать не нужно: используется Gradle Wrapper.

В IntelliJ IDEA нужно выбрать JDK 25+ для Gradle JVM и запуск тестов через Gradle.

## Запуск

Windows PowerShell:

```powershell
.\gradlew.bat run
.\gradlew.bat run --args="--seed 42"
.\gradlew.bat run --args="--help"
```

Linux и macOS:

```bash
./gradlew run
./gradlew run --args="--seed 42"
./gradlew run --args="--help"
```

Без аргументов seed выбирается автоматически и печатается в консоли.
Для повторения запуска передайте это число через --seed.

Seed может быть любым целым числом в диапазоне Java long:
от -9223372036854775808 до 9223372036854775807.

Одинаковый набор слов и одинаковый seed дают одинаковый ответ.
Изменение состава словаря может изменить ответ при том же seed.

Коды завершения приложения:

- 0 - успешный запуск или справка;
- 1 - ошибка создания игры;
- 2 - некорректные аргументы командной строки.

## Словарь

Основной ресурс: src/main/resources/dictionary.txt.

Формат: одно слово в строке, пять русских букв в нижнем регистре, без ё.

При загрузке удаляются внешние пробелы; пустые строки и комментарии,
начинающиеся с #, пропускаются. Некорректные слова вызывают ошибку.

WordDictionary допускает любой непустой набор корректных слов.
При создании игровой партии GameService требует минимум 50 уникальных слов.

## Устройство

- dictionary/WordDictionary - неизменяемый словарь, список для выбора ответа и множество для проверки наличия слова.
- dictionary/DictionaryLoader - чтение ресурсов и обработка ошибок загрузки.
- game/GameSession - состояние партии и контролируемая запись принятых слов.
- game/GameStatus - состояния IN_PROGRESS, WIN и LOSE.
- game/GameService - проверка параметров и создание партии по seed.
- Main - аргументы командной строки и демонстрационный вывод.

Порядок слов стабилен благодаря сортировке.
Счётчик попыток и статус вычисляются по истории.
История возвращается неизменяемым снимком.
На последней попытке угадывание имеет приоритет над поражением.

Конструктор сессии и запись хода доступны внутри пакета game.
Обработка пользовательского ввода будет добавлена в MR2.

## Проверки

Windows:

```powershell
.\gradlew.bat test
.\gradlew.bat spotlessApply check
```

Linux и macOS:

```bash
./gradlew test
./gradlew spotlessApply check
```

Все обязательные тесты MR1 включены.
Заготовки MR2 и MR3 пока отключены через @Disabled.

Проверяются границы размера словаря, неизменяемость данных, состояния сессии, независимость партий и запуск отдельного процесса.
