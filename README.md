# «5 букв»

Консольная игра на Java: нужно угадать русское слово из пяти букв за шесть попыток.

Реализованы требования MR1-MR3 и все дополнительные задания:
уровни сложности, категории слов, подсказка, статистика за запуск,
цветной вывод и replay.

## Требования

- JDK 25 или новее.
- Терминал с поддержкой UTF-8.
- Для цветного режима - поддержка ANSI-последовательностей.

Gradle отдельно устанавливать не нужно: используется Gradle Wrapper.

В IntelliJ IDEA выберите JDK 25 для Gradle JVM.
Сборку и тесты рекомендуется запускать через Gradle.

## Быстрый запуск

### Windows PowerShell

Перед интерактивным запуском настройте UTF-8 в текущем окне PowerShell:

```powershell
[Console]::InputEncoding = [System.Text.UTF8Encoding]::new($false)
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
```

Открыть меню:

```powershell
.\gradlew.bat --console=plain run
```

Открыть меню с фиксированным начальным seed:

```powershell
.\gradlew.bat --console=plain run --args="menu --seed 42"
```

Запустить одну партию без меню:

```powershell
.\gradlew.bat --console=plain run --args="--seed 42"
```

Показать справку:

```powershell
.\gradlew.bat --console=plain run --args="--help"
```

Параметр `--console=plain` отключает обновляемый индикатор Gradle, который может мешать интерактивному вводу.

Если после настройки UTF-8 корректные слова всё ещё отклоняются, повторите запуск без использования ранее запущенного Gradle daemon:

```powershell
.\gradlew.bat --no-daemon --console=plain run --args="--seed 42"
```

### Linux и macOS

Используйте терминал с кодировкой UTF-8:

```bash
./gradlew --console=plain run
./gradlew --console=plain run --args="menu --seed 42"
./gradlew --console=plain run --args="--seed 42"
./gradlew --console=plain run --args="--help"
```

Остальные примеры используют Windows PowerShell.
На Linux и macOS замените `.\gradlew.bat` на `./gradlew`.

## Правила игры

Программа загадывает слово из пяти букв.
На угадывание даётся шесть допустимых попыток.

- Регистр не учитывается.
- Внешние пробелы удаляются.
- Допускаются пять русских букв без `ё`.
- Слово должно присутствовать в словаре выбранной сложности и категории.
- Цифры, знаки и пробелы внутри слова отклоняются.
- Некорректный ввод не расходует попытку и не изменяет историю.
- Повторное допустимое слово расходует попытку.

После принятого слова выводится результат сравнения:

- ✅ - буква находится на правильной позиции;
- 🟡 - буква совпала с ещё не использованной буквой ответа на другой позиции;
- ❌ - для буквы не осталось совпадений.

Например, для ответа «озеро» и попытки «арбуз»:

```text
❌🟡❌❌🟡 арбуз
Осталось попыток: 5
```

### Повторяющиеся буквы

Каждая буква ответа используется не более одного раза.
Сначала учитываются точные совпадения, затем остальные.

Для ответа «сорок» и строки «оооом»:

```text
❌✅❌✅❌
```

Обе буквы «о» расходуются на точные совпадения на второй
и четвёртой позициях.

Это пример проверки алгоритма: обычная игра дополнительно
проверяет наличие введённого слова в выбранном словаре.

### Завершение партии

Угадывание, в том числе на шестой попытке, означает победу:

```text
Победа! Слово угадано за 4 попытки
```

После шести допустимых неверных попыток показывается ответ:

```text
Неудача. Загаданное слово: озеро
```

Завершённая партия не принимает новые попытки и подсказки.

Конец входного потока прерывает незавершённую партию
и закрывает приложение. Прерывание не считается поражением.

## Меню

Без аргументов программа открывает главное меню:

```text
1. Новая игра
2. Настройки
3. Статистика
0. Выход
```

После победы или поражения можно начать следующую партию
без перезапуска программы.

Некорректный пункт меню сопровождается сообщением об ошибке.
Приложение продолжает ждать допустимый выбор.

В настройках можно выбрать сложность, категорию и цветной режим.
Пункт `0` сохраняет выбранные значения и возвращает в главное меню.
Настройки применяются к следующим партиям и сохраняются
до завершения текущего запуска.

## Аргументы командной строки

Поддерживаются следующие формы запуска:

```text
five-letters
five-letters menu [--seed <число>] [настройки]
five-letters --seed <число> [настройки]
five-letters replay --seed <число> [настройки] --guesses [ввод...]
five-letters --help
```

`five-letters` здесь обозначает приложение.
При запуске через Gradle передавайте его аргументы через `--args`.

| Параметр | Значения | По умолчанию |
|---|---|---|
| `--difficulty` | `standard`, `easy` | `standard` |
| `--category` | `all`, `nature`, `everyday` | `all` |
| `--color` | `never`, `always` | `never` |

Seed необязателен в меню, но обязателен для одной партии и replay.

Параметры до `--guesses` можно передавать в любом порядке.
Повторные и неизвестные параметры, отсутствующие значения
и недопустимые значения вызывают ошибку запуска.

Используется форма `--seed 42`, а не `--seed=42`.

Пример запуска с настройками:

```powershell
.\gradlew.bat --console=plain run --args="menu --seed 42 --difficulty easy --category nature --color always"
```

## Сложность и категории

Сложность меняет состав словаря.
Число попыток во всех режимах остаётся равным шести.

- `standard` - обычный уровень;
- `easy` - вручную отобранный набор более простых слов.

Категории:

- `all` - все слова выбранной сложности;
- `nature` - природа;
- `everyday` - быт.

Для тематической категории используется пересечение
словаря сложности и словаря категории.

| Сложность | Все слова | Природа | Быт |
|---|---:|---:|---:|
| Обычная | 644 | 70 | 70 |
| Лёгкая | 120 | 60 | 60 |

Выбранный словарь используется и для загадывания ответа,
и для проверки попыток. Слово из другой категории может быть отклонено.

## Подсказка

Во время партии введите:

```text
:hint
```

Подсказка открывает первую слева позицию, которая ещё не была
раскрыта точным совпадением в предыдущих попытках.

Например:

```text
Подсказка: на позиции 1 находится буква "о".
```

- Одна успешная подсказка доступна за партию.
- Подсказка не расходует попытку и не добавляется в историю слов.
- Регистр команды и внешние пробелы не учитываются.
- Повторная подсказка отклоняется.
- Если все позиции уже известны из предыдущих попыток, подсказка не выдаётся и не расходуется.
- После завершения партии подсказки недоступны.

## Статистика

Статистика хранится только в памяти в течение текущего запуска.

Показываются:

- число начатых партий;
- победы;
- поражения;
- прерванные партии;
- число партий с использованной подсказкой;
- процент побед;
- среднее число попыток в выигранных партиях.

Процент побед считается среди завершённых партий:

```text
победы / (победы + поражения) * 100%
```

Прерванные партии не входят в этот показатель.
При отсутствии завершённых партий выводится `0.0%`.

Среднее число попыток учитывает только победы.
При отсутствии побед выводится `0.0`.

Статистика доступна в меню и выводится при завершении запуска.
После отдельной партии без меню также выводится её статистика.

Replay не включается в статистику игрока.

## Цветной вывод

Цвет выключен по умолчанию.
Включить его можно в настройках меню или аргументом:

```powershell
.\gradlew.bat --console=plain run --args="--seed 42 --color always"
```

В цветном режиме буквы принятого слова окрашиваются:

- зелёным - точное совпадение;
- жёлтым - совпадение на другой позиции;
- серым - отсутствие доступного совпадения.

Маркеры ✅, 🟡 и ❌ сохраняются.
Цвет не влияет на правила, выбор слова или результаты партии.

Для вывода без ANSI-последовательностей используйте `--color never`.
Автоматическое определение поддержки цвета не выполняется.

## Seed и воспроизводимость

Seed - целое число в диапазоне Java `long`:
от `-9223372036854775808` до `9223372036854775807`.

Одинаковые seed и выбранный набор слов дают одинаковый ответ.
Изменение сложности, категории или содержимого словаря
может изменить ответ при том же seed.

В меню без `--seed` начальное значение выбирается автоматически.
Seed каждой партии печатается перед игровым вводом.

Первая партия использует начальный seed.
Seed следующих партий последовательно получаются из
`Random`, созданного с этим начальным значением.

Просмотр статистики, изменение настроек и ошибки ввода в меню
не изменяют последовательность seed.

Для воспроизведения отдельной партии сохраните напечатанный seed,
сложность и категорию.

## Replay

Replay создаёт новую партию и последовательно обрабатывает
переданные строки без чтения с клавиатуры.

```powershell
.\gradlew.bat --console=plain run --args="replay --seed 42 --guesses арбуз сорок озеро"
```

Сценарий с настройками и подсказкой:

```powershell
.\gradlew.bat --console=plain run --args="replay --seed 42 --difficulty easy --category nature --guesses :hint арбуз озеро"
```

Эти примеры демонстрируют формат команды и не гарантируют победу.

- `--seed` и `--guesses` обязательны.
- Все настройки нужно указать до `--guesses`.
- После `--guesses` каждый аргумент считается вводом игрока.
- Поддерживается команда `:hint`.
- Каждый шаг показывает исходный ввод и результат обработки.
- Некорректные слова не расходуют попытки.
- Действия после завершения партии отклоняются.
- Пустой сценарий разрешён.
- Если попыток недостаточно для завершения партии, выводится «Партия не завершена.» без раскрытия ответа.

Пустой сценарий:

```powershell
.\gradlew.bat --console=plain run --args="replay --seed 42 --guesses"
```

Для одинаковых результатов нужны одинаковые seed, выбранный словарь
и последовательность входных строк.

Интерактивная игра и replay используют общую обработку действий.

## Словари

Ресурсы:

- `src/main/resources/dictionary.txt` - основной словарь;
- `src/main/resources/dictionaries/easy.txt` - лёгкий уровень;
- `src/main/resources/dictionaries/nature.txt` - природа;
- `src/main/resources/dictionaries/everyday.txt` - быт.

Формат - одно слово в строке, пять русских букв без `ё`.

Загрузчик читает UTF-8, удаляет внешние пробелы,
пропускает пустые строки и комментарии, начинающиеся с `#`.
Некорректные слова вызывают ошибку.

`WordDictionary` приводит слова к нижнему регистру через `Locale.ROOT`
и удаляет повторы после нормализации. Поиск не зависит от регистра.

Словарь неизменяемый. Сортированный список обеспечивает стабильный
порядок выбора по seed, а множество используется для проверки наличия слова.

`WordDictionary` допускает любой непустой набор корректных слов.
Минимум 50 уникальных слов проверяется при создании партии в `GameService`.

## Устройство проекта

- `word` - общие правила формата и нормализации слов.
- `dictionary` - неизменяемые словари, загрузка ресурсов
  и выбор словаря по настройкам.
- `settings` - сложность и категория.
- `game` - состояние партии, валидация попыток, сравнение букв,
  обработка слов и подсказок.
- `replay` - воспроизведение последовательности действий
  и неизменяемый результат.
- `statistics` - статистика за запуск и её снимок.
- `cli` - аргументы запуска, меню, настройки,
  консольный ввод и форматирование.
- `Main` - создание компонентов и запуск выбранного режима.

Игровая логика отделена от консольного ввода-вывода.

`GameActionService` направляет обычные слова в `GameService`,
а команду подсказки - в `HintService`.

`ConsoleResultPrinter` обеспечивает общий вывод результатов
для интерактивной игры и replay.

История сессии и результаты защищены от внешнего изменения.
Число использованных попыток и статус партии вычисляются по истории.

## Проверки

Запуск тестов:

```powershell
.\gradlew.bat test
```

Полная проверка:

```powershell
.\gradlew.bat check
```


Реализованы все обязательные тесты MR1, MR2 и MR3.
Отключённых тестов нет.

Проверяются:

- загрузка, нормализация, размер и неизменяемость словаря;
- все комбинации сложности и категории;
- воспроизводимость по seed;
- валидация ввода без расходования попытки;
- повторяющиеся буквы и приоритет точных совпадений;
- победа, поражение и запрет действий после завершения;
- меню, настройки и несколько партий подряд;
- подсказки и независимость состояния разных партий;
- статистика, включая прерывание и запуск нового процесса;
- replay и единые правила обработки действий;
- цветной вывод и отсутствие ANSI-кодов по умолчанию.

CLI-тесты запускают приложение отдельным процессом и передают ввод в UTF-8.

## Коды завершения

- `0` - нормальное завершение, включая победу, поражение,
  конец ввода, незавершённый replay и справку;
- `1` - ошибка выполнения приложения;
- `2` - некорректные аргументы командной строки.

Отклонённое игровое слово не является ошибкой запуска.

При ненулевом коде приложения задача Gradle `run`
тоже завершается ошибкой.

## Принятые ограничения

- Только слова из пяти русских букв без `ё`.
- В CLI всегда шесть попыток.
- Используются только встроенные словари.
- Лёгкий словарь и категории составлены вручную.
- Настройки и статистика не сохраняются между запусками.
- Replay получает действия из аргументов.
- Цвет включается явно и требует поддержки ANSI терминалом.
