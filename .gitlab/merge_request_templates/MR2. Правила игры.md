## Требования MR2

- [ ] `applyGuess(session, guess) -> GuessResult`
- [ ] Ввод без учёта регистра, только буквы, ровно 5, слово есть в словаре
- [ ] **Некорректный ввод не тратит попытку**
- [ ] Статусы букв `✅ 🟡 ❌`
- [ ] Определение победы и поражения
- [ ] Логика проверки отделена от консольного ввода-вывода

### Повторяющиеся буквы

Каждая буква ответа расходуется один раз: сначала отмечаются все `✅`,
затем оставшимися буквами закрываются `🟡`.

- [ ] `сорок` / `оооом` даёт `🟡❌❌✅❌`, а не `🟡🟡🟡✅❌`
